# Homosapiens #19053

Site-ul echipei de robotică FIRST Tech Challenge Homosapiens #19053, Colegiul Național „B. P. Hasdeu” Buzău. Publicat pe [homosapiens.ro](https://homosapiens.ro) prin Cloudflare, la fiecare push pe `main`.

Structura:

- `index.html`: pagina (toate taburile, textele în RO/EN/FR/ZH și logica)
- `support.js`: motorul care randează pagina
- `assets/img`, `assets/echipa`, `assets/sponsori`: poze și logo-uri
- `_headers`: reguli de cache pentru Cloudflare

Linkuri directe către taburi: `/#echipa`, `/#premii`, `/#despre`, `/#sponsori`, `/#contact`.
